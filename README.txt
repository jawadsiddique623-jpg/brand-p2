BRAND — BE REMARKABLE
======================

ফাইলসমূহ:
- index.html       : Home page
- collection.html  : Collection / Products page
- about.html       : About & Contact page
- style.css        : সব পেজের CSS
- assets/          : আপনার দেওয়া ছবি

চালানোর নিয়ম:
1. ZIP ফাইলটি Extract করুন।
2. brand_prime_website ফোল্ডার খুলুন।
3. index.html ফাইলে ডাবল-ক্লিক করুন অথবা VS Code-এ Live Server দিয়ে চালান।

নোট:
- JavaScript ব্যবহার করা হয়নি।
- পেজগুলোর মধ্যে HTML anchor link ব্যবহার করা হয়েছে।
- FAQ-তে HTML-এর details/summary ব্যবহার করা হয়েছে; এটি JavaScript ছাড়া খোলে/বন্ধ হয়।
- Add to Cart, Search, Wishlist এখন ডেমো লিংক; প্রকৃত কার্ট/চেকআউট চালাতে পরে backend বা JavaScript লাগবে।
- ফোন নম্বর, ইমেইল ও মূল্যগুলো ডেমো হিসেবে বসানো; প্রকাশের আগে নিজের সঠিক তথ্য দিয়ে বদলে নিন।
- লোগো ও পণ্যের ছবি assets ফোল্ডারে মূল ফাইল হিসেবে রাখা হয়েছে।
